4. Listas em HTML

As listas em HTML permitem organizar informações de forma estruturada. Existem três tipos principais de listas: listas ordenadas, listas não ordenadas e listas de definição

Exemplo Lista não ordenada:

  • Pastel
    • Massa
    • Proteina (Frango, carne, palmito)
    • Molho vinagrete (Opcional)
  • Crepe
    • Massa preparada
    • Proteina (Presunto, queijo, nutella, doce de leite)
    • Cobertura (Doces: brigadeiro, nutella e etc)
  • Bolo
    • Massa do bolo
    • Recheio (Morango, chocolate, brigadeiro, doce de leite)
    • Cobertura (Doces: brigadeiro, nutella, chantilly)

Exemplo Lista ordenada:

  1. Flamengo
  2. Athletico PR
  3. São Paulo
  4. Santos
  5. Corinthians

Exemplo Lista de definição

HTML
Linguagem de marcação utilizada para estruturar conteúdo na web
CSS
Linguagem de estilo utilizada para definir a aparência visual de páginas web
JavaScript
Linguagem de programação utilizada para adicionar interatividade e dinamismo ás páginas web

5. Links em HTML

A tag < a > cria um link com outro documento ou âncoras.

Exemplo link página externa:

<a href="https://google.com" target="_blank">Acesse o Google</a>

Clique aqui para abrir o Google

Exemplo link página interna:

<a href="pagina2.html" target="_blank">Acesso Página 2</a>

Clique aqui para abrir a Página 2

Exemplo Âncora:

<a href="#nome">Acesso ao item </a>

Clique aqui para ir para o inicio da página
