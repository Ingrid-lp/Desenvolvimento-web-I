4. Listas em HTML

As listas em HTML permitem organizar informações de forma estruturada. Existem três tipos principais de listas: listas ordenadas, listas não ordenadas e listas de definição.

Exemplo Lista não ordenada:

  • Pastel
    • Massa
    • Proteina (frango, carne, palmito)
    • Molho vinagrete(opcional)
  • Crepe
    • Massa preparada
    • Proteina (presunto, queijo, nutela, doce de leite)
    • Cobertura (doces: brigadeiro, nutela)
  • Bolo
    • Massa do bolo
    • Recheio (morango, chocolate, brigadeiro, doce de leite)
    • Cobertura (doces: brigadeiro, nutela, chantilly)

Exemplo Lista ordenada:

  1. Corinthians
  2. Athletico Paranaense
  3. Coritiba
  4. Santos
  5. Flamengo

Exemplo Lista de definição:

HTML
Linguagem de marcação utilizada para estruturar conteúdo na web.
CSS
Linguagem de estilo utilizada para definir a aparência visual de páginas web.
JavaScript
Linguagem de programação utilizada para adicionar interatividade e dinamismo às páginas web.

5. Links em HTML

A tag <a> cria links com outros documentos ou âncoras.

Exemplo link pagina externa:

<a href="https://www.google.com" target="_blank">Acesse o Google </a>

Clique aqui para abrir o Google

Exemplo link pagina interna:

<a href="pagina2.html" target="_blank">Acesso Pagina 2 </a>

Clique aqui para abrir a Página 2

Exemplo Ancora:

<a href="#nome">Acesso ao item </a>

Clique aqui para ir para inicio da pagina

6. Outras tags HTML

Tag <div>

É utilizada para agrupar elementos. É um elemento de bloco.

Tag <span>

É utilizada para formatação de elementos dentro de um texto. É um elemento de linha.

Tag <address>

É utilizada para especificar informações de contato do autor ou proprietário da página.

7. Imagens em HTML

A tag <img> é utilizada para inserir imagens em uma página web.

Exemplo:

<img src="imagem.jpg" alt="Descrição da imagem" width="300" height="200">

8. Tabelas em HTML

A tag <table> é utilizada para criar tabelas em uma página web.

<tr> - Cria uma linha na tabela

<th> - Cria uma célula de cabeçalho na tabela

<td> - Cria uma coluna de dados na tabela

Exemplo simples:

Nome Idade Cidade
João 25 São Paulo
Maria 30 Rio de Janeiro
Carlos 28 Belo Horizonte

Exemplo com Colspan e Rowspan:

Colspan: Atributo que permite mesclar colunas.

Notas alunos - Desenvolvimento Web I

Rowspan: Atributo que permite mesclar linhas
